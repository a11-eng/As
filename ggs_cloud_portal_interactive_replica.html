How to Access This Site on Any Device

Open on iPhone, Android, iPad, or any device on your Wi-Fi

1

Host Free on GitHub Pages or Vercel (Easiest for Mobile)

You can upload this index.html file to a free static host to generate a web link accessible from anywhere:

  1. Go to github.com and create a public repository.
  2. Upload this index.html file.
  3. In Settings > Pages, choose main branch and click Save. You will receive a live URL.
2

Share Over Your Local Wi-Fi (Python Server)

If your PC and phone are on the same Wi-Fi network, run a local web server:

cd /path/to/folder
python3 -m http.server 8000

Then open your computer's local IP on your phone's browser: http://192.168.x.x:8000

3

Save to Mobile Home Screen

When viewing the link on Safari (iOS) or Chrome (Android), tap Share / Options > Add to Home Screen to use it as a native web application.
